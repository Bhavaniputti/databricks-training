# Databricks Training

Welcome to the **Databricks Training** repository. This repository is used to maintain all training materials, SQL practice queries, outputs, notes, and assignments in a structured week-wise and day-wise format.

---

## Repository Structure

```text
databricks-training/
│
├── README.md
│
├── week1/
│   ├── day1/
│   │   ├── queries.sql
│   │   ├── output.txt
│   │   └── README.md
│   │
│   ├── day2/
│   │   ├── queries.sql
│   │   ├── output.txt
│   │   └── README.md
│   │
│   └── day3/
│
├── week2/
│   ├── day1/
│   └── day2/
│
└── resources/
```

---

## Purpose

This repository is maintained for:

- SQL practice
- Databricks learning
- Data Engineering training
- Maintaining daily progress
- Storing assignments and notes

---

## Folder Guidelines

### Week Folders
Each week will have a separate folder:

```text
week1
week2
week3
...
```

### Day Folders
Inside every week folder, create separate folders for each day:

```text
day1
day2
day3
...
```

---

## Files to Maintain

Each day folder should contain:

| File | Description |
|------|-------------|
| `queries.sql` | SQL practice queries |
| `output.txt` | Query outputs/results |
| `README.md` | Concepts learned and notes |
