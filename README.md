# Databricks Training

Welcome to the **Databricks Training** repository.  
This repository is maintained to organize all training materials, assignments, practice files, notes, and project work in a structured format throughout the training program.

---

## Repository Structure

```text
databricks-training/
│
├── README.md
│
├── week1/
│   ├── day1/
│   ├── day2/
│   └── day3/
│
├── week2/
│   ├── day1/
│   └── day2/
│
├── week3/
│
└── resources/
```

---

## Folder Organization

- Each week contains separate folders.
- Inside each week, daily work is maintained separately.
- Every day folder may contain:
  - SQL files
  - Output files
  - Notes
  - README files
  - Practice exercises
  - Assignments
  - Other training-related resources
